## 关键发现

1. **译文质量良好**:段落完整、术语一致、引用/DOI/URL 原样保留,右栏中文流畅可读。
2. **占位符保护有效**:`{v1}`、`<style id>`、`%d/%s`、`p < 0.05` 等全部原样保留。
3. **表格数字保真**:04-大表格的数值(41.2/39.8 等)与 "Engine A-D" 标识全部保留,表头正确翻译(模型/BLEU/COMET/延迟)。
4. **双栏右栏提取验证**:质检可正确提取右栏译文并统计术语命中。
5. **应用链路稳定**:四任务串行排队、进度实时推进(53→59→94→100)、全部产出质检报告与术语统计。

## 已知边界

- **qwen3 思考型模型不可用**:经 Ollama OpenAI 兼容端点,思考过程无法关闭,每段 1–3 分钟,整篇不可行。已验证 `/no_think` 软开关在该端点无效。推荐改用非思考型指令模型(qwen2.5:7b)。
- **扫描件(05)OCR 失败属预期**:BabelDOC OCR workaround 对本测试扫描件报 "document contains no paragraphs",任务正确标记失败。P2 规划的"译文旁注"方案待后续。
- 7B 模型的翻译能力有上限,长难句偶有直译痕迹——这是模型能力边界而非管线缺陷。
