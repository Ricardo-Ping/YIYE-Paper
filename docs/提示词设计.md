# 提示词设计（当前版本 v2）

> 本文记录翻译提示词的工程决策：引擎内部模板长什么样、同类项目怎么写、我们的提示词为什么这样设计。修改提示词时同步递增 `engine_worker.py` 里的 `PROMPT_VERSION` 并更新本文。

## 1. 提示词的真实结构

发给模型的每段请求由 **BabelDOC 引擎模板**组装，我们的提示词只是其中的"角色块"：

```text
{角色块 —— 我们的 custom_system_prompt}

## Rules（引擎内置，强制）
1. 结构完全不变：不增删改任何 tag、占位符、token
2. tag 保持不变（<style>、<b>…）；tag 内可读文本翻译；<code> 内不译
3. {v1}、{name}、%s、%d、[[...]]、%%...%% 等占位符不译不改
4. 整段是纯代码/标识符时原样返回
5. 全部可读内容译成目标语言

{术语块 —— 选中术语库后，引擎扫描每段文本，注入命中的词条}
{上下文块 —— 标题等上下文提示}

## Output
只输出译文，无解释、无反引号

正文：{段落文本}
```

**关键结论**：结构保护（公式/引用/富文本占位符）由引擎 Rules 硬性保证，提示词不应重复，否则稀释重点。

## 2. 同类项目的写法（调研）

| 项目 | 提示词风格 | 要点 |
|---|---|---|
| [PDFMathTranslate-next](https://github.com/PDFMathTranslate/PDFMathTranslate-next) | 极简（一句话人设 + 一条规则） | "professional, authentic machine translation engine"；不必译时（专名/代码/占位符）返回原文；NO explanations, NO notes |
| [BabelDOC](https://github.com/funstory-ai/BabelDOC) | 模板化，规则与角色分离 | 结构规则全部在 Rules；自定义 system prompt 只替换角色块，末尾自动补 "Follow all rules strictly." |
| [paper-translator](https://github.com/morning-cml/paper-translator) | 术语库驱动 | 术语库提升准确率 + DeepSeek 引擎，方向与我们一致 |

## 3. 我们的提示词（v2，全文）

```text
你是一位资深的学术翻译引擎，专门把英文科研论文翻译成{简体中文|繁体中文}。
- 忠实原文：不增写、不删减、不解释、不总结；原文没有的信息，译文里不能出现。
- 学术文风：使用规范书面语，符合中文学术论文的表达习惯；避免口语化和翻译腔。
- 术语纪律：术语表中给出的词条必须按给定译名翻译，并全文保持一致；术语表没有的专业术语按学界通用译法处理，没有把握时保留英文原名。
- 数字与单位：数值、单位、化学式、变量名保持原样，不换算、不改写。
- 长句处理：按{目标语言}习惯重组语序、断句，但不得改变原句的逻辑关系与限定范围。
```

### 设计原则

1. **不与引擎 Rules 重复**——结构保护交给模板，提示词只管内容层：忠实性、文风、术语、数字、句法重组。
2. **Qwen3 思考抑制**：模型名含 `qwen` 时自动前缀 `/no_think`，防止思考内容污染译文。
3. **目标语言动态生成**：简体/繁体分别生成（v1 的"英译中"写死问题已修复；日语已按产品决策移除）。
4. **忠实性是第一条**：学术论文翻译的首要失败模式是"LLM 自行补充/总结"，其次是术语不一致。

### 与质检的配合

提示词负责"要求"，质检负责"验证"：完成后的逐页检查会扫描输出 PDF 中的占位符残留（`{v1}`、`<style`）与术语应用情况（suspect/unseen），形成闭环。

## 4. 版本历史

| 版本 | 变更 |
|---|---|
| v1 | 三行基础版：忠实性 + 占位符保留 + 术语表（占位符部分与引擎 Rules 重复） |
| v2 | 重构为五条内容层规则；移除与引擎 Rules 重复的占位符条目；新增数字单位、长句重组、学术文风；目标语言动态生成 |

## 5. 修改提示词的注意事项

- 提示词是系统提示词（role_block），BabelDOC 会在其后自动追加 "Follow all rules strictly."——不要在提示词里写 "## Rules" 之类的标题，避免与模板结构混淆。
- 修改后递增 `PROMPT_VERSION`；引擎带翻译缓存，疑难排查时可对比清缓存前后的输出。
- 提示词对所有 provider 生效（OpenAI 系 / Anthropic / Gemini 经网关 / 本地 Ollama），保持语言中立、长度克制。
