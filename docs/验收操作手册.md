# P1 验收操作手册

> 目标:用真实模型跑通验收论文集,人工核对译文质量,完成调研文档第 8 节要求的 P1 验收。
> 预计耗时:环境准备 15 分钟 + 每篇论文 2–10 分钟(视模型与页数)+ 人工核对每篇 15–30 分钟。

## 1. 准备模型(二选一)

**本地 Ollama(推荐首选,论文不出本机):**

```powershell
# 从 https://ollama.com/download 安装后:
ollama pull qwen3:8b      # 8GB+ 内存/显存机器
ollama pull qwen3:4b      # 低配置备选(约 2.6 GB)
```

**云端 API(质量上限更高,注意费用与保密):**

任一 OpenAI 兼容服务的 key(DeepSeek / 硅基流动 / 智谱等),或 Anthropic / Gemini 官方 key(应用内置协议网关)。

## 2. 生成验收论文集

```powershell
.venv\Scripts\python.exe test\make_validation_papers.py
```

生成到 `validation-papers\`,五篇各验一类版式:

| 论文 | 验证点 |
|---|---|
| 01-单栏文本 | 常规单栏结构与段落完整性 |
| 02-双栏排版 | 双栏顺序、跨栏标题 |
| 03-公式与引用 | 数学记号、`[12]` 引用、DOI/URL、`{v1}` 占位符 |
| 04-大表格 | 表头与数字、小数点、负号是否保真 |
| 05-扫描件 | 无文字层:应正确警告,OCR 兼容模式可能失败(属已知边界) |

## 3. 翻译

1. 双击 `启动.bat`,浏览器打开 <http://127.0.0.1:4173>
2. 设置中配置服务,点"测试连接"确认 ✓
3. 批量拖入 `validation-papers\` 五篇 → 开"左右对照" → 开始翻译
4. 全部完成后逐篇人工核对(见下)

## 4. 人工核对清单(每篇过一遍)

**完整性**
- [ ] 无整段漏译(对照质检报告"疑似未翻译"页)
- [ ] 无大段英文残留

**术语**
- [ ] 关键术语译名前后一致(对照质检报告"术语 N/M 应用")
- [ ] 专名、算法名保留英文是否恰当

**公式与结构**
- [ ] 公式图形未被破坏、位置正确
- [ ] 引用编号 [12]、DOI、URL 原样保留
- [ ] 图表本身未被改动或丢失

**版式**
- [ ] 无文字溢出页边、无大面积重叠(质检会标 font_too_small / text_image_overlap)
- [ ] 字号可读(引擎会自动缩小适配,过小会标出)

**发现问题的处理**
- 个别页不可接受 → 任务列表勾选"第 X 页保留原文" → 生成修订版
- 术语不统一 → 编辑质检导出的术语表 CSV → 存入术语库 → 重翻
- 全部段落重翻需强制绕过缓存时,开"忽略翻译缓存"

## 5. 多模型对比(可选)

```powershell
# 按 test/benchmark-providers.example.json 写好服务列表后:
node test\benchmark.mjs --dir validation-papers --providers my-providers.json
```

生成各服务的耗时 / token / 质检问题对比表。注意:数据只回答"快不快、稳不稳",**译文好坏必须人工盲评**。

## 6. 结果记录

每篇论文记录一行(可存 `docs/acceptance-results.md`):

```
| 日期 | 模型 | 论文 | 完成 | 耗时 | tokens | 质检问题 | 人工结论(优/可用/不可用) | 备注 |
```

全部记录完成后,即可移除版本号的 alpha 后缀,宣告 P1 验收完成。
